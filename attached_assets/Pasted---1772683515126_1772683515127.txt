При входе в приложение показыватся приветственное сообщение "Привет, <имя>"  и под ним кнопка "Погнали". После нажатия на кнопку мы переходим в основное окно.
При загрузке основного окна - грузим все доступные ключи. Ключ - это дата в формате yyyy-MM-dd. Есть служебные ключи: 
- goals
- everyday
- done
После загрузки всех ключей мы выбираем ключи прошлых дней, выбираем сегодня и на 7 дней вперед. Мне нужно иметь темную и светлую темы - переключатель где-то наверху. Все загруженные задачи сортируем по дате и выводим списком, как на скрине: Бейдж дня, при нажатии на который сворачивается список задач этого дня и показывается цифра в скобках с количеством задач. При повторном нажатии разворачивается. Все просроченные дни помечаются 
красным цветом - как дни, так и задачи внутри. По умолчанию просроченные дни свернуты. Рядом с бейджем дня есть кнопка + для создания новой задачи. Форму создания определим позже. При выводе задачи в список нужно сделать форматирование, а именно все ссылки сокращать до 20 символов, добавляя ..., то так, чтобы ссылки были кликабельны и выделялись стилем как ссылки. Особая логика для списка на сегодня: сначала добавляются все задачи из goals, потом everyday, а только потом задачи из ключа дня. В карточке простой задачи (не goal и everyday) снизу идут кнопки "Завтра", "Через день", "Через неделю", "Через месяц", "Пн/Ср", "Вт/Чт", "Вых", "Custom", "Done" - можно придумать иконки понятные или более понятный текст, чтобы уместить все кнопки. При нажатии на Done - текст задачи помещается в список выполенненых и сохраняется в ключ done. При нажатии всех кнопок, кроме custom расчитывается дата переноса задачи с учетом, что все задачи планируются на рабочие дни (например завтра в пятницу перенесет задачу на понедельник, Если через месяц выпадает на выходной, то ищется первый рабочий день до, Пн/ср - выбирает следующий понедельник или среду, Вт/чт - следующий вторник, четверг или пятницу, Через день - также переносит через выходные на первый рабочий день, то есть для пятницы и четверга будет понедельник, для среды - будет вторник, для пн - среда, для вт - четверг. Вых - на близжайщий выходной день. После расчета даты показывается новое окно поверх, в котором выводится текст задачи, под ним выводится бейж с расчитанной датой в формате "Понедельник, 22 марта 2026" и под ним кнопки +/-, которые прибавляют и отнимают по одному дню, который тут же показывается в бейдже. При нажатии на бейдж даты показывает компонент для выбора дня. Текст в поле для ввода, чтобы пользователь мог отредактировать текст (позволяет делать многострочный ввод). Снизу окна кнопки Сохранить и отмена. При сохранении задача добавляется в нужный день и сохраняется в ВК ключ. При нажатии на Custom показывается то же окно и сразу же открывается диалог для выбора даты. При нажатии на кнопку + рядом с днем открывается окно это же окно с выбранной датой.
